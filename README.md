# Balatro: Dream BBQ Mod

Content mod for Balatro based on ENA: Dream BBQ. Currently adds 47 Jokers, 24 new consumables of a custom type, 2 Decks, and a new Stake chain consisting of 11 Stakes. It is at least intended to offer Vanilla-friendly balance... but no guarantees.

Offers support for JokerDisplay, CardSleeves, and CardPronouns
